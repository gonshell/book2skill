# graph-spec.md — 知识点图谱契约

> 状态：**骨架已冻结（2026-10-27 用户裁定），附录可扩**。这是 book2qa 唯一的硬契约：
> `build` 产出它，`ask` / `learn` / `drill` / `review` 全部消费它。
>
> **冻结范围**（改动须升 `b2q.graph/v2` + 迁移脚本 + 同步四个消费方）：
> §2 文件形态、§3 必填字段、§4 id 编码规则、§5 锚点不带偏移。
> **可扩范围**（追加不破坏既有断言，不升版）：§6 公式规则表、§8 节点清单，
> 以及 `exercises` / `figures` / `formulas` / `prereq` / `errors` 五个可选字段的**内容**。
>
> 冻结骨架、不冻附录的理由：id 与必填字段一旦变动，已产生的错题与掌握度全部错位；
> 而公式规则表与节点粒度需要真实数据检验，过早冻死会逼出迁移脚本。
>
> 版本：`b2q.graph/v1` · 2026-10-27 · 试点册：人教A版数学必修第一册

## 1. 组织原则

**以知识点为轴，不以书为轴。**

书的结构（册 → 章 → 节）只用于**定位**（页码、章节路径、排序），
不用于组织检索与学习。原因：学生问的是"单调性怎么判断"，不是"第 76 页讲什么"；
出题、掌握度、复习排程都必须落在知识点上，不能落在页码上。

### 1.1 节点成立判据（四选三）

一个候选节点要成立，须满足下表四条中的**至少三条**。判据的作用是把"粒度"从审美问题
变成可裁决问题——两个人用同一套判据，不该裁出 60 与 110 的差距。

| # | 条件 | 检验方法（可机械执行） |
|---|---|---|
| 1 | 教材有独立陈述 | 原文中存在完整的定义 / 定理 / 公式 / 步骤段落，不是括号里的半句话 |
| 2 | 能独立出题 | `drill` 能出 ≥3 道题，且不依赖其他节点即可判定对错 |
| 3 | 有专属易错点 | `errors` 能写出 ≥1 条**具体**错误（"容易混淆"这类空话不算） |
| 4 | 标题是学生说法 | 说人话；禁用"及其""相关""初步""综合"等含糊词 |

- 第 2 条是硬闸：出不够三道题，`drill` 对这个节点就是空的，等于没建。
- 第 3 条是防塞名词闸：写不出具体错误，说明它只是某个节点的附属结论，应进 `errors` 而非独立成节。

粒度对照：

| | 正例 | 反例（太粗） | 反例（太细） |
|---|---|---|---|
| 例子 | 「函数单调性的定义」 | 「函数的基本性质」 | 「增函数的符号记法」 |
| 判据 | 四条全符 | 含多个可独立考查的点，第 1 条不成立 | 拆开后无法单独出题，第 2 条不成立 |

### 1.2 规模与配额（必修第一册基准）

| 指标 | 基准 | 越界说明 |
|---|---|---|
| 节点总数 | **72–88** | 再少会漏检索入口（学生问法远多于节点名）；再多则 learn 分块过碎、review 每日到期数爆炸 |
| 单节点覆盖原文 | **2–4 页 / 15–60 行 md** | 半页 = 太碎；一整节 = 太粗 |
| 单节节点数 | **1–6** | 超 6 说明该节还有子节未拆；不足 1 说明该节只是习题页，应挂到上一节 |
| 类型配额（±5%） | concept 35–40% · theorem 15–20% · **method 25–30%** · skill 5–10% · application 5–10% | method 不足 → 检索偏向"是什么"、答不到"怎么办"，而后者才是学生的提问主体 |

这些数字不是硬门槛，而是**报警线**：build 报告里越界的节要单独列出，由人给理由，
不自动改。

### 1.3 合并与拆分的三条铁律

1. **易错点不独立成节点，除非它自己能出题。**
   「一正二定三相等」→ 独立（求最值题的成败判据，可单独出题）；
   「集合中元素的互异性」→ 归 `errors`（永远只在别的题里考）。
2. **定义与"由该定义导出的判定"分开**（单调性定义 / 用定义判定单调性）。
   学时是两步，考时是两种题型。
3. **应用型按模型分，不按题分**（一次函数模型 / 分段函数模型），否则节点数会随习题膨胀。

## 2. 文件形态

一行一个节点（JSONL），UTF-8，字段按 §3 定义：

```
data/graph.jsonl
```

不单独存边文件：前置关系以 `prereq` 数组内嵌在节点里（v1 只有一种边）。
若将来需要 `related` / `contrast` 等弱关系，另加 `edges.jsonl` 并升 v2。

## 3. 节点字段

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `id` | ✅ | string | 稳定标识，见 §4。**一旦发布不得修改**（错题、掌握度按它索引） |
| `title` | ✅ | string | 知识点名称，学生的说法（如「函数单调性的定义」） |
| `type` | ✅ | enum | `concept` 概念 / `theorem` 定理公式 / `method` 方法 / `skill` 技能 / `application` 应用 |
| `book` | ✅ | string | 册名，与 book2md 产物目录名一致（如 `必修第一册`） |
| `chapter` | ✅ | string | 章标题原文 |
| `section` | ✅ | string | 节标题原文（保留原书的编号写法） |
| `pages` | ✅ | [int, int] | 教材页码区间（**教材页**，非 PDF 物理页）；取自 `page_map.md` |
| `summary` | ✅ | string | 一句话说明（≤60 字），用于检索与列表展示 |
| `anchors` | ✅ | object[] | 原文锚点，见 §5。至少 1 条 |
| `exercises` | ⬜ | object[] | 教材题目索引，见 §5.1。**`ask` 的「P76 第 3 题」与 `drill` 的「教材原题」依赖它** |
| `figures` | ⬜ | string[] | 关联图号（如 `图3-5`），须在 `figures.json` 中可解析 |
| `formulas` | ⬜ | object[] | 关键公式，见 §6 |
| `prereq` | ⬜ | string[] | 前置知识点 id（无前置则缺省，不写空数组） |
| `errors` | ⬜ | string[] | 常见错误（一句一条），供 drill 的错因分析使用 |
| `status` | ✅ | enum | `verified` 已人工核对 / `unverified` 内容存疑（见 §7） |
| `built_at` | ✅ | string | ISO8601，建库时间 |
| `built_by` | ✅ | string | `manual` 人工录入 / `auto` 规则生成 / `auto+review` 生成后人工改过 |

字段命名一律 snake_case；不得出现 `pages_text`、`page_no` 之类的同义字段。

## 4. id 编码规则

```
M1-C3-S2-K04
│  │  │  └─ 该节内知识点序号（两位，01 起）
│  │  └──── 节序号（节标题的 3.2 → S2；若该节有子节，见下）
│  └─────── 章序号（阿拉伯数字）
└────────── 册代码：M1 必修一 / M2 必修二 / X1 选必一 / X2 选必二 / X3 选必三
```

子节处理：`3.2.1 单调性与最大（小）值` → `M1-C3-S2A-K01`（子节用 `S2A` / `S2B`），
父节本身若不是仅作容器、而是有独立内容，用 `M1-C3-S2-K00` 表示"节级概述"。

**稳定性要求**：id 与内容绑定，不与位置绑定。重跑 build 时同一知识点必须得到同一 id
（靠 `section + title` 的确定性映射），否则已有错题会错位。

## 5. 锚点（anchors）

```json
{"physical_page": 76, "quote": "一般地，设函数 f(x) 的定义域为 I……", "section_path": "第三章/3.2.1/单调性的定义", "role": "definition"}
```

| 字段 | 说明 |
|---|---|
| `physical_page` | PDF 物理页，用于从 book2md 产物反查（`markdown.md` 的页界标记按它分段） |
| `quote` | 原文摘录（20–120 字），**唯一可靠的重定位依据** |
| `section_path` | 章/节/子节路径，便于人眼核对 |
| `role` | 可选：`definition` 定义段 / `motivation` 动机或追问段 / `warning` 注意事项 / `example` 例题 |

**`role` 为什么必要**：学生问的多是"为什么"（retrieval.md §1 实测十句有八句如此），
而 `anchors` 如果只收定义句，答"为什么必须说任意"时就只能靠 BM25 撞运气去找动机段。
一条节点建议收 1–3 条 anchors，其中至少一条 `definition`，能收到 `motivation` 更好。

**不存字符偏移量**。产物重跑后偏移必变，存了就失效；`quote` 在任何一次重跑后
都能用文本匹配重新定位。这是刻意选择：宁可定位慢一点，不要锚点悄悄失效。

### 5.1 题目索引（exercises）

v1 初期草案漏了题目层，而 `ask` 的三大入口之一是「P76 第 3 题怎么做」，
`drill` 要出"教材原题"，两者都需要"题 → 知识点"的反查。故在节点内嵌：

```json
"exercises": [{"label": "P76 练习 3", "page": 76, "quote": "已知函数 f(x)=x²+2x…（题干前 40 字）"}]
```

- 抽取来源：「练习 / 习题 / 复习巩固 / 综合运用 / 拓广探索」块内的题号行，**外加 `例N` 例题**
  （实测：3.2.1 里第一个可用的题就是「例1」，`ask` 接"这题怎么做"时最常命中的也是例题）。
- 例题可拆三段：题干（`例N` 到 `分析`）、思路（`分析：` 段）、解答（`解：` 段）。
  `ask` 讲思路与 `drill` 判分都要用，故 `quote` 取题干，另存 `analysis` / `solution`。
- 量级：必修一约 500–700 条。内嵌而不单开 `problems.jsonl`——单开会引入"一题属多知识点"
  的多对多关系，v1 不值得为它加一层 join；将来真需要再升 v2。
- 抽不准（缺题号、题干跨页、块归属不明）**一律进 `build_report.md`，不猜**。

## 6. 公式双轨

```json
{"latex": "$f(x_1) < f(x_2)$", "plain": "f(x1) < f(x2)"}
```

- `latex`：原样保留，用于渲染给学生看。
- `plain`：文本化副本，**用于检索**。否则学生问"根号二是有理数吗"永远搜不到 `$\sqrt{2}$`。

文本化规则表（v1 最小集，写进 `book2qa/formula_plain.py`）：

| LaTeX | plain | LaTeX | plain |
|---|---|---|---|
| `\frac{a}{b}` | `a/b` | `\sqrt{x}` | `根号x` |
| `x^{2}` | `x^2` | `\alpha` … `\omega` | `alpha` … `omega` |
| `\le` `\ge` `\ne` | `<=` `>=` `!=` | `\in` `\cup` `\cap` | `属于` `并` `交` |
| **`\leqslant` `\geqslant`** | `<=` `>=` | **`\forall` `\exists`** | `任意` `存在` |
| **`\subseteq` `\subset`** | `包含于` `真包含于` | **`\mathbf{R}` `\mathbb{R}`** | `R` |

**归一化必须先于规则匹配**（实测产物里真实存在的写法）：

1. 去空白：`$I { \subseteq } D$` → `\subseteq`；
2. 别名折叠：`\leqslant`→`\le`、`\geqslant`→`\ge`、`\mathbb{R}`→`\mathbf{R}`；
3. 再套上表；表里没有的保留去符号版并标 `degraded`。

不做第 1、2 步，上表一半规则在真实数据上都不会命中（`\leqslant` 是最常见的漏网写法）。

新增规则须同时补单测（`tests/test_formula_plain.py`）。

## 7. 质量闸：`status` 的判定

`unverified` 不是"没写完"，而是"**这段内容本身可能不可信**"，两种来源：

1. book2md 的 `broken_formulas.tsv` 命中的知识点（OCR 结构性损坏公式）；
2. 人工核对时发现原文与本节点结论不一致。

消费约束（**强制**）：`ask` / `learn` / `drill` 引用 `unverified` 节点时，答复里必须
带一句「此处教材内容识别存疑，建议对照纸质书 P{页}」。不允许静默使用。

## 9. 与 book2md 产物的对接

输入目录（单册）：

```
<book_dir>/markdown.md     带页界标记 <!-- ===== 原书物理页 7-46 · 教材页码 None-39 ===== -->
<book_dir>/images/         图片（markdown 中以 (images/xxx.jpg) 引用）
<book_dir>/page_map.md     物理页 → 教材页 映射表
```

页界标记与 `page_map.md` 是**页码溯源的唯一依据**，不得靠猜。

## 10. 已知的结构缺陷（build 必须处理，不得回避）

| 缺陷 | 实测（必修第一册） | 处理 |
|---|---|---|
| **标题层级被压平** | `##` 共 436 个，`#` 仅 2 个，`###` 为 0 —— 章/节/小节/思考/练习全在同一级 | 按文本模式分**四类**（§10.1），重建层级 |
| **章名被拆行** | `## 第五章` 与 `## 三角函数` 分两行（第 6768、6770 行） | 章标题后紧跟同级标题且非节格式时，视为章名续行合并 |
| **OCR 污染标题** | `## 思考`、`## da`、`## ••`、`## 3思考` 等数十处 | 走 §10.2 归并规则，**不设"丢弃"分支** |
| **编号缺空格** | `## 2.3二次函数…`、`## 3.4函数的应用（一）`、`## 5.4三角函数的图象…` | 正则容错：`^\d+\.\d+` 后可有可无空白 |
| **TOC 是全书合订** | `gzsx-md/final/TOC.md` 混了五册（第五章条目其实是选必二的导数） | 单册章节**只从 markdown.md 提取**，不读合订 TOC |

这五项不是可选项——不做标题重建，节点边界必然错，后面五套 skill 全歪。

### 10.1 标题四分类（每条 `##` 只有四种去处）

| 类 | 匹配模式 | 层级动作 |
|---|---|---|
| 章 | `^第[一二三四五六七八九十百]+章` | 开章；允许续行合并（见上表第 2 行） |
| 节 | `^\d+\.\d+(?!\.)`（与汉字之间可有可无空格） | 开节 |
| 子节 | `^\d+\.\d+\.\d+` | 开子节 |
| 提问块 | 思考 / 观察 / 探究 / 归纳 / 练习 / 习题 / 复习巩固 / 综合运用 / 拓广探索 / 阅读与思考（允许前后缀数字与空格） | **保留正文内容，不开节点、不作节边界** |

四类必须覆盖全部 `##`：正则全都落空时按提问块处理（宁可多并正文，不许静默丢弃）。

> 早期草案把"噪音"列为第五类并允许丢弃，与固定块里的「思考」自相矛盾
> （同一个 `## 思考` 既是固定块又是噪音），且丢弃等于静默丢内容。已改为四类 + 归并。

### 10.2 OCR 污染标题的归并规则

1. 去掉首尾空白与零散符号（`••`、`·`、`*`）；
2. 去掉长度 <4 汉字且不含数字分隔符的残留（`da` 丢弃；`3思考` → `思考`）；
3. 归并后若命中提问块关键词 → 归入提问块；若只剩空串 → 并入上一段正文，不产生节点、不作边界；
4. 每一次归并都记入 `build_report.md`（原行号 + 原文本 + 归并结果），供人工复核；
5. 归并**只动标题行，不动正文**——正文一个字符都不许丢。
