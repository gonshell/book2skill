## 2. S1 页锚定（全链最硬的一步）

### 2.1 三套页码，别混

| 来源 | 编号体系 | 实测 |
|---|---|---|
| `<!-- 原书物理页 47-86 · 教材页码 40-79 -->` | **原书物理页**，40 页一块 | 全书 7 块，7–270 |

三者关系：`教材页 = 物理页 − 7`（该册）；`PDF 页 ≠ 物理页`，**不能直接当页码用**。

### 2.2 但块内偏移恒定（这是关键发现）

逐块统计图片页范围（实测）：

| 块（物理页） | 图片页范围 | 偏移 = 首图页 − 块首页 |
|---|---|---|
| 7–46 | 12–51 | 5 |
| 47–86 | 92–131 | 45 |
| 87–126 | 172–211 | 85 |
| 127–166 | 252–290 | 125 |
| 167–206 | 332–371 | 165 |
| 207–246 | 412–450 | 205 |
| 247–270 | 493–515 | 246 |

每块首尾都对得上（如 92→47、131→86），说明**块内 PDF 页与物理页一一对应**。
于是每张图都是一个**逐页锚点**：

```
offset(block) = 块内首张图页 − 块首物理页
physical_page = 图片页 − offset(block)
book_page     = page_map[physical_page]
```

验证：`page_128` 在块 47–86（offset 45）→ 物理页 83 → `page_map` 第 83 行 = 教材页 **76** ✓
（正是 3.2.1 单调性所在页）

### 2.3 没有图的页面怎么办

| 情况 | 处理 | Issue |
|---|---|---|
| 段落前后都有图锚点 | 页区间 = [前锚, 后锚]，取前锚为 `physical_page` | — |
| 只有前锚 | 页 = 前锚（可能偏小 1 页） | `page_estimated` |
| 整块无图 | 页 = 块首页 | `page_block_only` |
| page_map 缺该物理页 | `book_page=None` | `pages_missing` |

**不许向下取整假装精确**：`page_estimated` 的节点在 `build_report` 里单列，
人工核对该段是否真在前锚页。

## 5. S4 公式双轨（规则表要按真实变体补）

真实文本用的是 `\leqslant` / `\forall` / `{ \subseteq }`，而 graph-spec §6 原表只写了 `\le`。
按实测补：

| 真实写法 | plain |
|---|---|
| `\leqslant` / `\geqslant` | `<=` / `>=` |
| `\forall` | `任意` |
| `\exists` | `存在` |
| `{ \subseteq }`（带空格） | `包含于` |
| `\mathbf{R}` | `R` |
| `\in`（`\in I`） | `属于` |

**先去空白再去花括号**：`$I { \subseteq } D$` 先规整成 `\subseteq`，否则任何规则都匹配不上。

## 6. S5 题目抽取：例题也要抽

原设计只抽「练习/习题/复习巩固」，实测这段里第一个可用的题是 **`例1`**——
`ask` 接"这题怎么做"时最常命中的就是例题。所以抽取范围改为：

`练习` / `习题` / `复习巩固` / `综合运用` / `拓广探索` / **`例N`**

例题还有固定结构 `分析：` / `解：`，可拆成三段：题干（例N 到"分析"）、思路（分析段）、
解答（解段）——`drill` 判分和 `ask` 讲思路都要用。
