# retrieval.md — 问题理解与检索

> 上一版（pipeline.md §4）把检索写成"精确 → 术语 → 题干 → 回问"的顺序回退，
> 且拿「P76 这个单调性……」当例子。**这是错的**：学生的话里通常没有任何定位信息。
> 本文件替换那一节。

---

## 1. 先看学生真的会怎么说

| 真实问法（原话） | 定位信息 | 他要什么 |
|---|---|---|
| 单调性为什么一定要说"任意"两个数？ | **零** | 概念动机 |
| 空集为什么是任何集合的子集？ | 零 | 概念动机 |
| 奇函数在 x=0 处一定有定义吗？ | 零 | 边界条件 |
| 求值域都有哪些方法？ | 零 | 方法清单 |
| 这题第二问我不知道怎么下手（贴题干） | 只有题干 | 思路起点 |
| 我算出来是 2，答案是 1/2，哪错了 | 自己的解法 | 判错 |
| 什么时候用换底公式？ | 零 | 选用条件 |
| 函数一点都听不懂 | 零（范围过宽） | 找切入点 |
| 今天该复习什么 | 零（问的是"我"） | 排程 |
| 那为什么这步是这样？ | 指代上一轮 | 承接 |

十句里有**八句不含页码、题号、节号**。任何把"精确定位"放在第一优先的检索设计，
等于先把八成问题判成"未命中"，再来怪学生不会提问。

## 2. 问题类型（先分类，再决定走哪条路）

| 类型 | 语言信号 | 需要什么材料 | 主 skill |
|---|---|---|---|
| `concept_why` 概念追问 | 为什么 / 一定要 / 是什么 / 有什么区别 / 能不能 | 节点 + 定义段 + **动机段/提问块** | ask |
| `stuck` 卡题 | 贴题干、指某一步、出现数字或符号 | 题干 → 题所属节点 + 原文例题 | ask |
| `check_work` 判自己答案 | 我算的 / 我这样写 / 哪错了 | 学生解法 + 该节点 `errors` | ask |
| `method_list` 方法清单 | 有几种 / 什么时候用 / 怎么想到 | **跨节聚合 `type=method` 的节点** | ask |
| `too_broad` 范围过宽 | 学不懂 / 完全不会 / 一点都 | 章级提纲（structure） | learn（反问聚焦） |
| `schedule` 排程/复习 | 复习什么 / 考考我 / 我忘了 | `store.sqlite` 到期清单 | review |
| `follow_up` 承接 | 这 / 那 / 它 / 这一步 | 上一轮 context | 同上一轮 skill |

分类不靠模型猜，靠**语言信号 + 会话状态**：出现"为什么/一定要"进 `concept_why`；
带 `我算/我写/哪错` 进 `check_work`；只有 2–5 个字且含"复习/考我"进 `schedule`。
分类错了也不致命——它只决定**输出模板**和**召回侧重**，不决定答不答。

## 3. 三路并行召回（不是顺序回退）

顺序回退的致命问题：精确入口一落空，后面就只剩"节点层"检索；而**学生的困惑常常落在
正文段落里，那段话并不在节点的 `anchors` 中**（anchors 只存定义那 1–2 句）。
所以改成三路同时跑，再融合：

| 路 | 检索对象 | 干什么 |
|---|---|---|
| **R1 术语** | `title`(×3 权重) + `aliases` + `summary` + `errors` + `formulas.plain` | 学生说的是"知识点名"或"易错点里的词" |
| **R2 段落** | 节内正文**段落**（按页界 + 空行切）→ 段落所属节 | 学生说的是一句**教材原话里的词**（"任意""一定能"） |
| **R3 结构** | 页码 / 题号 / 节号 / 图号（精确相等） | 少数真的带了定位的问题 |
| **R4 向量** | node/para/ex 三池语义近邻（bge-small-zh，ONNX） | 同义改写、口语化问法（"我忘了诱导公式"）；模型未装自动降级三路 |

四路的索引形态、写入/读出与按场景的排序差异见 [serving.md](serving.md)。

融合用 RRF（Reciprocal Rank Fusion，k=60），取 top5，每个候选带 `evidence`：

```
{node_id | null, section, para_span, matched_terms, score, route}
```

**为什么 R2 必须有**：学生问"为什么一定要说任意"，"任意"这个词在
`errors[0]` 里（R1 能中），但教材真正的解释在定义段后面的「思考」块里
（"你能举出两个特殊值满足 f(1)<f(2) 但函数不单调的例子吗"）——那段**不是节点**，
R1 永远拿不到，只有 R2 能。

## 4. 命中段落 ≠ 命中节点

段落有三种归属，都要能答，但落库方式不同：

| 段落归属 | 能否回答 | 依据怎么写 | 是否计入掌握度 |
|---|---|---|---|
| 节点 `anchors` 覆盖 | 能 | 「必修一 P76 §3.2.1」 | 计入该节点 |
| 提问块（思考 / 探究 / 归纳） | 能 | 「必修一 P76 §3.2.1『思考』」 | **不计入**（无节点） |
| 例题解析 | 能 | 「必修一 P77 例 2」 | 计入例题所属节点 |

新增契约字段：`anchors[].role`（`definition` / `motivation` / `warning` / `example`），
让 `concept_why` 优先取 `motivation` 段，而不是每次靠 BM25 撞运气。

## 5. 承接与指代

"那为什么这步是这样？"没有任何可检索的词。规则：

1. 出现"这/那/它/这一步/上面"且无其他定位信号 → 绑定 `context.jsonl` 里**上一轮的命中节点**；
2. 若上一轮是解题，同时带上"上一轮输出的第 N 步"（输出里每个步骤有编号）；
3. 连续 2 轮无命中 → 强制回问，不许继续猜。

## 6. 输出模板按类型分叉（"思路→步骤→易错点→依据"不是万能模板）

| 类型 | 模板 |
|---|---|
| `concept_why` | **一句话直答** → 教材原话（引原文）→ **若无此条件会怎样**（反例）→ 易错点 → 依据 |
| `stuck` | 思路（下一步该想什么）→ 步骤 → 易错点 → 依据 |
| `check_work` | 先指出错在第几步（引 `errors` 对应条目）→ 正确做法 → 依据 |
| `method_list` | 方法逐条（一句说明 + 适用条件 + 出处页码）→ 建议先练哪个 |
| `too_broad` | 给 3 个具体切入点让学生选，不直接开讲 |
| `schedule` | 只给清单，不讲解 |

上一版把"思路→步骤→易错点→依据"当成所有回答的统一格式，对 `concept_why` 是错的：
问"为什么"的人要的是**动机与反例**，给他四个步骤等于答非所问。

## 7. 复习场景：以排程为主，检索为辅

复习时学生的话分成两种，处理方式完全不同：

| 学生说 | 走什么 | 讲解规格 |
|---|---|---|
| 今天该复习什么 / 考考我 | **不检索**，直接读 `store.sqlite` 的 due 列表 | 不进讲解，只出 3–5 题 |
| 我忘了诱导公式 / 这个知识点忘了 | 走 §3 召回 → 命中节点 | **复习模式**：≤3 句话讲完 + 立刻 1 题验证，禁止长篇（复习 ≠ 精学） |

复习模式的硬约束：**不许重复 `learn` 的完整讲解**。学生在复习阶段要的是"唤起"，
不是"重学"；长篇讲解会让他放弃复习。这一条要写进 `SKILL.md`。

## 8. 兜底三级（不许编）

| 情况 | 动作 |
|---|---|
| top1 分数 ≥ 阈值且与 top2 有差距 | 直接答 |
| top3 分差小（互相接近） | 答，但开头一句「你问的是不是『X』？」允许纠正 |
| 全部低于阈值 | **回问**：给 3 个候选切入点（按章聚合），一个具体结论都不给 |

阈值由 S2 阶段用 30 条真实问法标定；标定前先按经验值跑，跑完再定。

### 8.1 "问不好"分三类，机制不同

| 类型 | 例 | 机制 |
|---|---|---|
| 模糊 | 函数一点都听不懂 | §8.2 收敛环 |
| 不专业 | 就是那个增啊减啊的 | R1 查 `aliases`、R4 吃口语；低置信时**先答再确认**（答错一轮可纠，反问必废一轮） |
| 前提错 | 奇函数是不是一定过原点？ | 不是检索失败。正常命中节点，`errors` 提供纠前提素材：先纠前提（引 errors 原句）→ 再答他真正要的 |

### 8.2 模糊问法的多轮收敛（clarify 不是一次性的）

```
第0轮  intent=too_broad → 不检索 → 生成 3 个切入点 + "或把卡住的题贴过来"
第1轮  点选=精确命中（选项自带 section）｜改述=带上文重走四路｜
       都不是=记 deny list，选项下沉一层（章→节→子块），已否定项不再出现
上限 2 轮。第 3 轮仍模糊 → 降级进 learn 模式从头正讲，
"不对你就打断我"——把"你来描述"换成"我来讲你纠正"
```

**切入点生成三规则（全部来自数据，模型不编）**：

1. **结构候选**：上文所在章/节的下一级节（`structure.jsonl`，按学习顺序），每项带一句 hint；
2. **易混候选**：召回分接近的 top2–3 节点 title——分数接近本身说明学生卡在概念之间；
3. **错误候选**：候选节点 `errors` 转成问句（"你是不是遇到『用特殊值代替任意』的问题？"）。

**状态存 `context.jsonl`**：已给过的选项、deny list、当前收敛层。连续 2 轮无命中
强制回问（§5 规则 3）与本节收敛上限共用一个计数器，不叠加。

## 9. 与向量路的接口（已落地）

本文起草时向量路留作 v2 预留；现已定版落地为 **R4**，见 serving.md。
签名 `recall(query, k) -> list[Candidate]` 不变；R1/R2/R4 的 scorer 均可替换，
图谱与 skill 逻辑不动。**注意**：§3 的裸 BM25 曾在真实数据上失败
（"任意两个等边三角形"压过单调性定义段，见 serving.md 探针记录），
因此 R2 必须是"词表定节 + 节内排序"的两段式，不能裸跑。
