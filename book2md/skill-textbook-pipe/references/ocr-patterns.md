# OCR 错识模式知识库（references/ocr-patterns.md）

来自人教A版数学五册转换实战沉淀的**方法论知识**（不是转换逻辑——逻辑在核心包
`packs/math/` 与引擎探测器 D1–D10）。用于帮对话助手理解扫描报告、判断 C 档存疑项。

## 一、MinerU 常见错识形态（数学教材实测）

| 形态 | 表现 | 裁定线索 |
|---|---|---|
| 顶点符号 bar | `\bar{A}` 被识别为别的记号或丢失 | 看教材该处是否为顶点带横线记号 |
| overribbon 误识 | `\overrightarrow{AB}` 误为 `\widehat{...}` | 向量记号处重点排查 |
| 花括号错位 | `A}'` 类畸形（右侧撇号带花括号） | 公式渲染错位必查此项 |
| 多余否定号 | `\not` 后接普通字母（本应是比较运算） | 逻辑符号处排查 |
| 中文引号进公式 | `\mathrm{~"..."}` 引号混入 | 中文语境公式排查 |
| 水印图 | 整页水印裁片混入 images/（D6 已自动检测） | 通常直接判误报可删 |
| 顶点 bar 误识 / 页码噪声 | 页眉页脚页码混入正文（postprocess 已清理） | 对照 PDF 页眉 |

## 二、已知**不可信**信号（裁定必读）

1. **图片文件名页号 ≠ 物理页**：MinerU 返回的 `page_K_*` 跨块不一致
   （实测同一本书既有绝对页−1 也有近绝对页）。唯一可依赖的不变量是
   "md 引用与图片文件同步改名"。裁定图片位置时**永远以 PDF 目检为准**。
2. **末页教材页码缺失属正常**：page_number 检测不到时页码映射记 None。
3. **渲染无误 ≠ 内容与原书一致**：质量门只保渲染与结构；内容保真靠人工抽检。

## 三、新学科接入时的预期

化学/物理教材的公式体系不同（化学方程式、物理单位），上述模式**不会直接照搬**；
首本新学科教材的任务之一就是沉淀该学科的错识模式清单（本文件按学科分节追加，
规则本体进核心包 packs/<学科>/）。
